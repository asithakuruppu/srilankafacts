# catalog/

Reviewed metadata in YAML and small CSVs, kept in Git. Nothing here is generated by hand-waving: every entry records its source and rights.

- `sources/`: one file per publisher or source (who, URLs, access, rights).
- `datasets/`: one file per dataset (source, licence, schedule, pipeline module, `spatial` block).
- `indicators/`: indicator definitions (unit, universe, aggregation rule, method notes).
- `geographies/`: schemes, vintages, code crosswalks (`codes/`), relations, manual-review queue.
- `spaces/`: vector-space definitions (recipe, metric, entity types), see `docs/architecture/vector-space-model.md`.

Schemas and the validator arrive with prompt F02. Field names follow `docs/architecture/data-model.md` and `docs/architecture/footprint-model.md`.
