# Sri Lanka Facts

*Every place in Sri Lanka, every number about it, with its source.*

Sri Lanka Facts is a spatial-first, vector-native data platform for Sri Lanka. Every value is stored with where it applies, when, and what it measures, traced to its source; places, buildings and indicators sit in shared vector spaces so they can be compared by distance. It will be published as a map-first website, open downloads and an API.

**Status:** Stage 0 (foundations). The repository is bootstrapped; no real data is published yet.

| Folder | What |
|---|---|
| `catalog/` | Reviewed metadata: sources, datasets, indicators, geographies, vector spaces |
| `overrides/` | Human corrections with evidence |
| `pipeline/` | Python data pipeline (`slf`) |
| `web/` | Next.js website |
| `tiles/` | Map tile recipes |
| `docs/` | Vision, architecture, decisions, roadmap, prompts |
