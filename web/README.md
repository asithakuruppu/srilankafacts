# web/

The Sri Lanka Facts website: Next.js (App Router, TypeScript strict), managed with pnpm.

Today it is a placeholder page. The persistent map shell, place pages and indicator pages arrive in Stage 1 (prompts W01 to W06). Commands are listed in the root `AGENTS.md`.

`AGENTS.md` in this folder is generated by Next.js and warns agents that this Next.js version may differ from their training data.
