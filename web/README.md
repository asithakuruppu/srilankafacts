# web/

The Sri Lanka Facts website: Next.js (App Router, TypeScript strict), managed with pnpm.

The home page is the map-first atlas (`src/components/atlas/`, method in `docs/methods/atlas.md`); place, indicator, table, data and methods pages are server-rendered. The atlas needs the bundle from `uv run slf atlas export` (run in `pipeline/`); without it the home page shows a readable summary. Commands are listed in the root `AGENTS.md`.

`AGENTS.md` in this folder is generated by Next.js and warns agents that this Next.js version may differ from their training data.
