# Contributing

Sri Lanka Facts is built by a product lead working with AI agents. Before changing anything, read [AGENTS.md](AGENTS.md): it holds the standing rules, conventions, commands and the report format every change must end with.

- One task per branch and pull request.
- Every number must trace back to a source (see `docs/architecture/data-model.md`).
- Decisions live in [docs/decisions/decision-log.md](docs/decisions/decision-log.md); don't contradict an Accepted decision without proposing a new one.
- Code is Apache-2.0 ([LICENSE](LICENSE)). Data we publish is CC BY 4.0, OpenStreetMap-derived data ODbL (D-005).
