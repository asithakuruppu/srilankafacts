# G03: Geometry QA report and QGIS review pack

| Stage | Workstream | Version | Last revised | Status |
|---|---|---|---|---|
| 0 | Geography | 1 | 2026-11-07 | active |

## When to use
After G01 (parallel to G02), and whenever a boundary source or version changes.

## Read first
- `AGENTS.md`
- `docs/lanka-data-layer-audit.md` §10 (caveat: their checks ran on simplified geometry) and §11 (NSDI area differences)
- G01 QA report and outputs

## Inputs (fill in)
```
VINTAGE: e.g. cod-ab-v03
THRESHOLDS: overlap area (default 0.01 km²), gap area, outside-parent share
```

## Task
1. On **canonical (unsimplified)** geometry: validity (with reason), self-intersections, empty geometries, multipart counts and holes.
2. Siblings per parent: overlaps and gaps above thresholds (in EPSG:5235), plus slivers. Coverage of the country polygon by provinces, districts, DS and GN (missing area, coastal and water edges).
3. Compare shapes with NSDI boundaries for districts and DS divisions if NSDI geometry can be retrieved politely: intersection-over-union per unit, and the largest differences. Compare areas with NSDI `adjusted_area`, noting that its definition is unknown.
4. Repairs: produce a `make_valid` version where needed, flagged `repaired: true`. **Keep the original.** Record which version tiles and analysis should use, as a recommendation.
5. Build a **QGIS review pack** for the lead: a `.qgz` project with styled layers (levels, issues layer, NSDI comparison) and a 10-item checklist of places to inspect, with what to look for and why (largest overlaps, biggest area differences, coastal gaps, Ampara).
6. Write `docs/research/geography/geometry-qa-{{vintage}}.md` with tables and thumbnails (static PNG maps generated by script).

## Constraints
- Report findings. Don't edit geometry beyond the flagged `make_valid` copy.
- Respect NSDI's service limits. If geometry retrieval is impractical, say so and skip step 3.

## Verify (show real output)
Summary counts per check per level; the list of top offenders; confirmation that the project file opens (layer list).

## Deliverables
QA report, issues GeoPackage layer, QGIS project and checklist.

## Done when
The lead can spend one hour in QGIS following the checklist and understand the boundary quality.

Report using the format in `AGENTS.md`.
