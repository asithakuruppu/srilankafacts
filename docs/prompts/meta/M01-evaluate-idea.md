# M01: Evaluate an idea from the opportunities register

| Stage | Workstream | Version | Last revised | Status |
|---|---|---|---|---|
| any | Strategy | 1 | 2026-11-07 | active |

## When to use
When an idea in `docs/ideas/opportunities-register.md` looks worth pursuing, or a new idea arrives. Nothing enters the roadmap without this.

## Read first
- `AGENTS.md`
- `docs/ideas/opportunities-register.md` (the idea entry)
- `docs/vision/vision-and-strategy.md`, `docs/roadmap/development-strategy.md`, `docs/decisions/decision-log.md`

## Inputs (fill in)
```
IDEA: OPP-NN (or a new idea description)
```

## Task
1. **Verify the premises:** does the data exist? In what form? Who publishes it, under what rights (R01/R02-lite)? Who else already does this (R03-lite)? Mark findings ✅/🟡/❓.
2. **Demand signals:** evidence from user research, search interest or client requests. Say "none yet" if there is none.
3. **Fit:** does it build on the spine and strengthen D-001, or pull away from it?
4. **Effort and cost:** steps, dependencies (which prompts and stages), the lead's verification load, running costs. State the assumptions.
5. **Risks:** rights, sensitivity, maintenance burden, reputation.
6. **Recommendation:** pursue now / schedule for Stage N / park (with reason). If pursuing, write a scoped proposal: deliverables, exit criteria, prompts to use or create.
7. Update the register entry (status, findings) and draft a decision-log entry if the roadmap should change.

## Constraints
- Be willing to recommend parking. A good "no" protects the flagship.

## Verify (show real output)
Sources for every premise checked.

## Deliverables
Updated register entry; proposal or parking note; draft decision-log entry if relevant.

## Done when
The lead can decide in five minutes.

Report using the format in `AGENTS.md`.
