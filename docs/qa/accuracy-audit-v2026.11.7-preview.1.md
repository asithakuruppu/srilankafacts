## Method

- Release: `v2026.11.7-preview.1`. Seed: **20261112**.
- Sample size target: max(100, 2% of 490 headline values) = 100. Drawn: **207** of 200,774 published values.
- Strata: every country and provisional-unit value; every `not_available` value; values a manual match changed (Kandalama/Kiralessa); then a fixed number per indicator at each level (province 2, district 2, ds 2, gn 5).
- For each value: parse the `source_locator`, open the raw snapshot by its sha256, read the cell (or sum the raw rows by the DCS code the locator names), recompute derived values with formulas written independently of the ingest code, and compare. Counts must match exactly; derived values within 5.1e-05; density within relative 0.0001 (area is recomputed here in EPSG:5235 from the release geometry).
- For GN rows the audit also checks **row identity**: the raw row's DCS code must be the code the crosswalk (`catalog/geographies/codes/dcs-census2024.csv`) gives for that GN.
- The API check reads `api/v1/places/{id}.json`, the file the website renders (`web/src/lib/release.ts`).

## Findings that are not value errors

1. **`source_locator` column numbers are 0-based.** `column 9 ('Total')` is Excel column **J**, not I. The header name in brackets is correct, but a person reading 'column 9' in Excel lands on the GN number column. Recommendation: a separate fix PR writes the Excel letter (`cell J352`) into locators. The confirmation sheet already uses Excel letters.
2. **Derived-value locators name both workbooks even for indicators that use one** (for example sex ratio uses only the population workbook). Harmless, but imprecise.
3. **Aggregate locators give a row range, not the rows.** For DS 1103 the range 6-40 happens to be contiguous; the audit sums by DCS code instead, which is what the range means.

## Not covered

- **Website rendering** (number formatting on the page) is not checked here: the audit checks the JSON the website reads. A display check needs the built site.
- **Area** for density is recomputed from the same COD-AB geometry the pipeline uses, so it checks the arithmetic, not the boundary.
- **Age and sex at national level** are checked against the workbook only; the Final Report pages for those tables were not parsed.
- This audit re-traces values; it cannot detect an error that DCS itself published.
