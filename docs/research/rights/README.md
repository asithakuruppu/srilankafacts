# Rights memos (prompt R02)

Not legal advice. Each memo classifies our intended uses against the source's own terms, with evidence, and lists questions for the publisher. Anything material is flagged for a Sri Lankan lawyer.

Intended uses assessed everywhere: (1) display on the website; (2) redistribution of the original files; (3) redistribution of derived tables (downloads, API); (4) commercial use (paid services); (5) modification; (6) share-alike obligations; (7) compatibility with our output licences (CC BY 4.0 for derived work, ODbL for OSM derivatives).
