**Subject:** Sri Lanka Facts: a place-based data project, and how we might complement LDF

I'm [Name], working on Sri Lanka Facts, an early-stage, independent project building an open, map-based reference of Sri Lankan places and statistics: every GN division, DS division and district, with the official figures about it and a link to the source (https://github.com/asithakuruppu/srilankafacts).
