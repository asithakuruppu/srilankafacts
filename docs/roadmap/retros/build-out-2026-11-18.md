# Retrospective: autonomous build-out, 2026-11-17 to 2026-11-18 (M02)

## What happened

The lead asked for every coding stage to be built with review moved to the end. Work ran as nine phases, each one branch and one PR merged to `main`, two of them (Phases 2 and 3) in a parallel session; a third session acquired open spatial data and built the landscape roll-ups.

## What went well

- Data and rights, not code, set the limits; every gap is named in the review queue instead of being filled with placeholders.
- Cross-checks caught real problems before merge: a header overflow, a hydration mismatch, events in Wikidata place lists, a translator file with the wrong column, an 11-minute polygon merge.

## What to change

- Performance has drifted: the atlas now carries about 70 MB of bundle files; a GN view on a slow phone takes about 44 s. Tiles (G04) should come before more layers.
- Many machine-drafted labels accumulated at once; reviewing them is now the main work.
- The prompts for Stage 2 and 3 (`draft`) should be refreshed with M03 to match what exists.

## Estimates

The engineering for Stages 2 to 4 that the data allows took about two days of agent time. The roadmap's months for those stages were mostly verification, rights and partnerships, which remain.
